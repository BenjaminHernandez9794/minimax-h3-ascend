# Fisher Pose「无限姿势 + 无限视角（支持双人）」工作流（Work-Fisher/ComfyUI-Fisher-Pose）
# 节点安装: bash scripts/install_nodes.sh fisherpose   （已包含在 qwen21 / qwen21-full 里）
# 工作流: custom_nodes/ComfyUI-Fisher-Pose/workflows/【Work-Fisher】无限姿势+无限视角（支持双人）.json
#
# 用法:
#   bash scripts/download_models.sh -l fisher_pose.txt --dry-run            # 先看清单与大小
#   bash scripts/download_models.sh -l fisher_pose.txt                      # 默认：正面摆姿，约 25.6GB
#   bash scripts/download_models.sh -l fisher_pose.txt --with angle         # 再加换机位 6 个文件，约 +3.9GB
#   bash scripts/download_models.sh -l fisher_pose.txt --with te_int8       # 文本编码器换 INT8（17.5GB → 9.4GB）
#
# 标签:
#   (无标签)  Qwen Image 2.1 INT8 主模型、Qwen3-VL 8B bf16 文本编码器、VAE、VNCCS 姿势 LoRA   约 25.6GB
#   angle     换机位：AnyAngle LoRA + TripoSplat 一套（工作流里该分组默认静音）            约 3.9GB
#   te_int8   用 qwen3vl_8b_int8_convrot 代替 bf16 文本编码器（与 qwen_image_2.1_turbo 清单共用同一文件），
#             省 8GB 下载与显存；工作流 CLIPLoader 需改选这个文件（类型仍是 qwen_image）
#
# 文件名与工作流默认选择完全一致，放在模型根目录（无子目录），Linux 上无需重选。
# 照片识别姿势另需 comfyui_controlnet_aux（DWPreprocessor，首次运行自动下 DWPose 权重），不在本清单内。
# 与 qwen_image_2.1_turbo 清单共用的文件（VAE、te_int8）已存在会自动跳过。
